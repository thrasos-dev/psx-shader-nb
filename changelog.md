# PSX Shader NB

## [1.3] - 21/10/2026

- Added a Cloud Style option under Sky Settings: Vanilla, Flat and Blocky
- Added a Cloud Haze option under Sky Settings, on by default: a half-transparent layer around Flat and Blocky clouds
- Added a Vanilla Fog option under Post Processing Settings, on by default. Minecraft's fog now shows where it is thick: the Nether, blindness, darkness, lava, powder snow, under water, and modded dimensions with thick fog
